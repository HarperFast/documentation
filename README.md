# Harper Documentation

Documentation website for [Harper](https://harper.fast), a fullstack, serverful Node.js application platform.

Hosted at [docs.harper.fast](https://docs.harper.fast). Powered by [Docusaurus](https://docusaurus.io/).

## If the site is down

The site runs on Harper Fabric, with a standby copy on GitHub Pages. [CONTRIBUTING.md](CONTRIBUTING.md#if-docsharperfast-is-down) says how to check which host is failing and how to fail over.

## Contributing

This documentation site is open source!

If you notice something out-of-place or have suggestions for improvement, please feel free to submit an issue and/or a pull request. Issues are filed through templates and organized by **type** (Bug / Feature / Task), **area** (`content` / `platform`), and **release milestone** (`v5.x`).

For more information on contributing — including issue conventions — follow the [contribution guide](CONTRIBUTING.md#reporting-issues).
